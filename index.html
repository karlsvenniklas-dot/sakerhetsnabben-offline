Kontrollerar

Förbereder appens filer för användning utan internet.

Version 1.7 · Kontrollerar filer

  1. Öppna app-länken direkt i Safari och välj Dela → Lägg till på hemskärmen.
  2. Öppna appen från den nya ikonen med internet på.
  3. Vänta tills det står Offline redo. Prova sedan att öppna appen i flygplansläge.

Vid problem: skicka texten efter ”Orsak” så går det att se vad som blockerar. Rensa inte webbplatsdata och ta inte bort appen om du har uppgifter som saknar säkerhetskopia.

Installation och uppdateringar behöver internet. Mejla, kartor och eventuell röstdiktering kan behöva uppkoppling. QR-avläsning beror på webbläsarstöd; objektnumret kan alltid anges manuellt.

Importera objektlista

Klistra in kolumner från Excel eller välj en CSV-fil (UTF-8). Första raden ska innehålla rubriker. En rad per uppdrag. Samma objekt kan ha flera olika ordernummer. XLSX-filer behöver först sparas som CSV.

Inga ändringar sparas förrän du godkänner importen.

Du väljer att uppdatera, hoppa över eller skapa ett nytt objekt. Order sparas separat från kundobjektet. Tomma fält raderar inte tidigare uppgifter. Ordernummer och telefonnummer behålls som text. Planerad till anges som ÅÅÅÅ-MM-DD. Ta gärna en säkerhetskopia före import.

Säkerhetskopia

Objekt, utkast, protokoll och bifogade dokument sparas i telefonens lokala databas. Inga arbetsuppgifter skickas till en server av appen.

Säkerhetskopian är inte krypterad. Förvara den säkert. Import från den tidigare SäkerhetSnabben stöds. Befintliga poster med samma ID ersätts efter bekräftelse.
